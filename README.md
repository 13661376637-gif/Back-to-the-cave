# Back to the Cave - Video Edition

WebXR + Three.js immersive puzzle experience for Meta Quest 3.

## Source package

The complete saved source package, including assets and the wall-marquee animation, is available directly in this repository.

## Local preview

Open `index.html` through a local HTTPS-compatible server, then enter VR from a Meta Quest 3 browser. The project includes the existing controller and flashlight interaction logic.
